# GitHub

Manage repository work: issues, pull requests, release notes, branch hygiene, and operational coordination.

## Use When
- The task centers on repository operations rather than code authoring alone.
- The user needs issue triage, PR planning, or release coordination.
- Repository state and collaboration workflow matter.

## Default Workflow
1. Identify the repo, branch, PR, or issue scope first.
2. Summarize current state, blockers, and required actions.
3. Recommend the smallest safe next operation with rationale.
4. Return concrete commands, issue/PR updates, or release notes as needed.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
