# Capability Evolver++

Run a deeper evolution pass that combines failures, successful patterns, and strategic gaps into a longer-horizon improvement roadmap.

## Use When
- The agent or system needs strategic capability growth, not just tactical fixes.
- Multiple weak signals point to a broader maturity problem.
- The user wants a staged improvement roadmap.

## Default Workflow
1. Collect failures, wins, bottlenecks, and missed opportunities.
2. Group them into tactical, structural, and strategic capability themes.
3. Define staged improvements with validation loops and rollback points.
4. Return a roadmap with short-, medium-, and long-horizon bets.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
