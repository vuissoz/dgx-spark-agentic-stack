# GOG (Google One GPT)

Assess Google One AI/Gemini/GPT-style consumer offerings, plans, feature bundles, and tradeoffs.

## Use When
- The user asks about Google One AI, Gemini, or bundled assistant offerings.
- You need a plan comparison or migration recommendation.
- Pricing, limits, or feature packaging matter to the decision.

## Default Workflow
1. Clarify region, timeframe, and the exact plan(s) under consideration.
2. Compare capabilities, limits, pricing, and lock-in factors.
3. Separate confirmed facts from marketing claims or inferences.
4. Return a recommendation with exact dates and confidence limits.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
