# Literature Scout

Map the relevant research, primary sources, and citation trails for a topic before deep analysis.

## Use When
- The user needs a research landscape scan.
- Primary literature and source discovery matter.
- The goal is breadth and canonical references before synthesis.

## Default Workflow
1. Define the topic, date range, and source quality bar.
2. Find primary papers, surveys, benchmarks, and official artifacts.
3. Cluster the literature into themes, schools, and gaps.
4. Return a reading map with highest-priority sources first.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
