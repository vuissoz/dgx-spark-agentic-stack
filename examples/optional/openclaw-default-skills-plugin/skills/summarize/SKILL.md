# Summarize

Compress long material into a precise summary without dropping the core facts, decisions, or unresolved risks.

## Use When
- The input is long, repetitive, or multi-source.
- The user needs a brief but faithful digest.
- You must preserve decision-relevant facts and caveats.

## Default Workflow
1. Identify the audience and target length.
2. Extract goals, facts, decisions, and unresolved questions.
3. Remove repetition and low-signal detail.
4. Return the summary plus any critical omissions or uncertainty.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
