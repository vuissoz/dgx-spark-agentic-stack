# Decision Assistant

Structure ambiguous choices into options, criteria, tradeoffs, and a defensible recommendation.

## Use When
- The user is choosing between multiple paths.
- The decision has competing criteria or uncertainty.
- A recommendation must be explicit and auditable.

## Default Workflow
1. List the options and define the decision criteria.
2. Score or rank options against the criteria.
3. Surface assumptions, reversibility, and downside risk.
4. Return a recommendation with rationale and trigger conditions for revisiting it.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
