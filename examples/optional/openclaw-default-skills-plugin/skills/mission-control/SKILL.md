# Mission Control

Coordinate complex work across phases, dependencies, owners, blockers, and progress updates.

## Use When
- The task spans multiple phases or workstreams.
- There are dependencies, risks, or handoffs to track.
- The user needs a control-plane view rather than deep execution detail.

## Default Workflow
1. State the mission, scope, deadlines, and constraints.
2. Break work into tracks with entry/exit criteria.
3. Track blockers, risks, and next decisions explicitly.
4. Return a concise status board with recommended next moves.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
