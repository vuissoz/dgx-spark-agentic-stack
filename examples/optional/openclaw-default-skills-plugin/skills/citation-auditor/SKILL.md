# Citation Auditor

Check that claims are supported by the right sources, quoted accurately, and not overstated.

## Use When
- A document has many citations or evidence-sensitive claims.
- The user wants to reduce unsupported or misrepresented references.
- You need claim-to-source traceability.

## Default Workflow
1. Extract the material claims and their supporting citations.
2. Check whether each citation actually supports the claim made.
3. Flag missing, weak, outdated, or misleading support.
4. Return a repair list with the highest-risk citation issues first.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
