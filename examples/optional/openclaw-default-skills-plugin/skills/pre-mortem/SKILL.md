# Pre-Mortem

Assume the initiative failed and work backward to identify the most probable causes before execution.

## Use When
- A project or launch is still pre-execution.
- The user wants to reduce avoidable failure risk.
- Organizational, technical, and adoption risks all matter.

## Default Workflow
1. State the objective and what failure would mean.
2. Imagine the future failure state and enumerate causes.
3. Sort causes into preventable, detectable, and irreversible risks.
4. Return leading indicators, mitigations, and owner-ready actions.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
