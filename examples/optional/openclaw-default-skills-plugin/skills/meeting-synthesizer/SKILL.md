# Meeting Synthesizer

Turn raw meeting notes or transcripts into decisions, action items, risks, and follow-up questions.

## Use When
- The input is a transcript, notes dump, or messy discussion log.
- The user needs actionable outcomes rather than a raw recap.
- Ownership and next steps matter.

## Default Workflow
1. Identify participants, context, and the meeting objective.
2. Extract decisions, disagreements, action items, and deadlines.
3. Separate facts from suggestions or unresolved debate.
4. Return a clean synthesis with owners and open questions.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
