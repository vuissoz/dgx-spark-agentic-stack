# Capability Evolver

Analyze recurring failures, friction, and missed opportunities, then propose concrete capability improvements.

## Use When
- Detect repeated failure patterns or inefficiencies.
- Separate signal from one-off noise.
- Propose safe, testable improvements with rollback.

## Default Workflow
1. Collect the relevant run logs, artifacts, or outcomes.
2. Cluster problems into patterns, root causes, and triggers.
3. Recommend the smallest changes with expected benefit and validation steps.
4. Return a prioritized evolution plan with risks and acceptance checks.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
