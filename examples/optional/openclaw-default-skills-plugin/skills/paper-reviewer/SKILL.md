# Paper Reviewer

Review a paper for contribution clarity, method soundness, evidence quality, and limitations.

## Use When
- A paper, preprint, or benchmark report needs critique.
- The user wants strengths and weaknesses, not just a summary.
- Method quality and evidence sufficiency matter.

## Default Workflow
1. State the claimed contribution and target problem.
2. Inspect the method, evaluation design, baselines, and ablations.
3. Separate supported conclusions from overstated claims.
4. Return verdict, strengths, weaknesses, and follow-up questions.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
