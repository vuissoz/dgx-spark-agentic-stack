# Grant Writer

Turn a project concept into a grant-ready narrative with goals, impact, method, milestones, and evaluation.

## Use When
- The user needs a grant concept note or proposal draft.
- Funders, milestones, and evaluation criteria matter.
- The narrative must connect need, method, and measurable impact.

## Default Workflow
1. Clarify the funder, call, audience, and constraints.
2. Define problem statement, objectives, work plan, and expected impact.
3. Make milestones, risks, and evaluation concrete.
4. Return a structured draft plus missing inputs and compliance gaps.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
