# Knowledge Gap Detector

Find what is still unknown, weakly supported, or missing in a research or delivery context.

## Use When
- The current answer or plan feels incomplete.
- The user wants explicit uncertainty and missing evidence.
- You need to prevent false confidence.

## Default Workflow
1. Define the questions the material should answer.
2. Compare those questions against current evidence and artifacts.
3. Classify the missing pieces by importance and ease of closure.
4. Return the gap list with recommended next evidence to collect.

## Output
- Return a concise, decision-ready result with assumptions, risks, and recommended next steps.
- If evidence is weak or missing, say so explicitly instead of over-claiming.
